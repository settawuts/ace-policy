## 1. Privacy Policy (นโยบายความเป็นส่วนตัว)

Our application collects basic user profile information provided by third-party authentication services (such as Facebook Login, TikTok Login, or Google OAuth). This information includes:
* Public profile information (Name, Profile Picture)
* Email address

### How We Use Your Data
We use the collected information solely for:
* Authenticating and verifying user accounts on our platform.
* Displaying user profile details within the app/website.
* Providing core application features and support.

We do NOT sell, trade, or share your personal data with third parties.

### Data Security
We store your data securely and implement appropriate technical measures to prevent unauthorized access or disclosure.

## 2. User Data Deletion Instructions (ขั้นตอนการขอลบข้อมูลผู้ใช้)

If you wish to remove your data or disconnect your account from our application, you can do so through the following methods:

### Method 1: Remove App Access via Social Provider (Facebook / TikTok)
1. Go to your Social Account Settings (e.g., **Facebook Settings & Privacy** > **Settings** > **Apps and Websites**).
2. Find our application name and click **Remove**.
3. Choose to request data deletion if prompted by the platform.

### Method 2: Direct Contact Request
You can request full account and data deletion directly from our team:
* **Email:** pures.s@hotmail.com
* **Subject:** Request Account Data Deletion
* **Processing Time:** Requests will be processed within 7-14 business days.
